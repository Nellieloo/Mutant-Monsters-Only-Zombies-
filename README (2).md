# Mutant Monsters (Fork)

Это форк мода **[Mutant Monsters](https://github.com/Fuzss/mutantmonsters)** для Minecraft, доработанный под личные нужды.

## Об оригинале

Mutant Monsters добавляет в игру мутировавших версий ванильных мобов Minecraft — каждый со своими уникальными способностями и наградами.

Сразитесь с Мутант-зомби, Мутант-скелетом, Мутант-крипером, Мутант-эндерменом и другими — каждый приносит новый вызов. Создавайте мощные предметы, приручайте взрывоопасных питомцев и открывайте странных новых существ вроде Spider Pig.

### Основные мутанты
- 🧟‍♂️ **Mutant Zombie** — мощные удары; за убийство даёт Hulk Hammer
- 🏹 **Mutant Skeleton** — меткий стрелок; из его костей крафтится броня
- 💥 **Mutant Creeper** — цепные взрывы; оставляет Creeper Minion Egg
- 🌀 **Mutant Enderman** — телепортация; отрубленная рука даёт Endersoul Hand
- ☃️ **Mutant Snow Golem** — союзник, кидающийся глыбами льда

2. Требуются зависимости: **Puzzles Lib**, **Fabric API** (для Fabric), **Forge Config API Port** (для Fabric)
3. Скачайте jar-файл из [Releases](../../releases)
4. Поместите в папку `mods`
